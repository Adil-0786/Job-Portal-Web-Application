# Job Portal Web Application

A full-stack web application designed to connect job seekers with employers.  
This project allows users to create profiles, search for jobs, and apply online, while employers can post job listings and manage applications.

---

## 🚀 Features
- **User Authentication**: Secure login and registration for job seekers and employers.
- **Profile Management**: Job seekers can create and update resumes; employers can manage company profiles.
- **Job Listings**: Employers can post jobs with detailed descriptions and requirements.
- **Search & Filter**: Job seekers can search jobs by title, location, or category.
- **Application Tracking**: Employers can view applicants and job seekers can track their applications.
- **Responsive Design**: Optimized for desktop and mobile devices.

---

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript (React recommended)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB / MySQL
- **Version Control**: Git & GitHub
